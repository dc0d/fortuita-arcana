# Operational Guidelines

## Naming Document Files

A document file is located inside the `docs/*` directory or its subdirectories. The name of a document file must follow the format `YYYYMMDD-<daily counter>-<title>.md`.

- **WHEN** the date is used in naming a file, **ALWAYS** get the current date first.
- **ALWAYS** choose a proper `<daily counter>` that reflects the sequence of documents created on the same day. The first document of the day should have a counter of `01`, the second `02`, and so on.

Examples:

- `20240601-01-act-1-prelude.md`
- `20240601-02-research-psuche.md`
